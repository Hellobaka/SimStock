# SimStock

QQ群聊的模拟炒股插件。
[AMN2](https://github.com/Hellobaka/Another-Mirai-Native2) 插件，要求 AMN2 版本 2.13.1 以上。

Fully Developed by DeepSeek V4 Pro


```plain
🌿 === 水银韭菜机 帮助 ===

💰 【账户管理】
/股票开户        | 创建账户，获得初始资金
/股票账户        | 查看余额、持仓、挂单
/股票出金 金额   | 取出账户资金

🔧 【管理员命令】
/股票入金 QQ 金额  为指定用户增加资金
/股票重置 QQ       重置指定用户的账户
/股票管理 添加 QQ  添加插件管理员
/股票管理 移除 QQ  移除插件管理员
/股票管理 列表     查看本群管理员

📈 【行情查询】
/股价查询 代码/股票名 | 查询实时股价
  示例: /股价查询 sh688525
  示例: /股价查询 佰维存储
  前缀: sz深市 sh沪市 bj北交所

💹 【交易操作】
/买入股票 代码/股票名 数量 | 市价买入
/卖出股票 代码/股票名 数量 | 市价卖出
/梭哈 代码         | 梭哈买入（余额全仓）
/限价梭哈 代码/股票名 价格 | 限价梭哈（余额全仓）
/限价买入 代码/股票名 数量 价格 | 挂限价买单
/限价卖出 代码/股票名 数量 价格 | 挂限价卖单
/股票撤单 订单号 | 撤销挂单
/清仓 代码/股票名 | 清仓指定股票
/全部清仓 | 清仓账号全部持仓
/授信额度 | 查询授信额度与欠款
/使用授信 金额/ | 借用授信（输入'梭哈'用满剩余额度）
/偿还授信 金额 | 偿还授信本金
/开盘清仓 代码/股票名/全仓 | 预约下一开盘（9:31/13:01）清仓
/取消开盘清仓 代码/股票名/全仓 | 取消开盘清仓订单
/开盘梭哈 代码/股票名 | 预约下一开盘（9:31/13:01）全仓买入
/取消开盘梭哈 代码/股票名 | 取消开盘梭哈订单

🔍 【信息查询】
/股票排行          本群交易排行榜
/全局排行          全局交易排行榜
/历史订单          个人交易历史
/查询订单          查看挂单与开盘预约
/股票帮助          显示本帮助

⚠️ 【交易规则】
- T+1制度: 当日买入的股票次日方可卖出
- 涨跌停限制: ±10%，涨停只能卖、跌停只能买
- 停牌股票无法交易
- 手续费: 成交金额的0.03%，最低5元
- 仅支持A股交易（不含指数/基金/债券）
- 交易单位: 100股（1手）的整数倍
- 交易时段: 工作日 9:30-11:30 13:00-15:00
- 限价单在满足条件时自动成交
- 不明确交易所时请加前缀，如 /买入股票 sz000001 100
```
